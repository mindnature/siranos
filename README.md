# SiranOS

An open-source, local-first personal AI memory and digital-self toolkit.

> **Status: early-stage prototype.** The extension source and tests are developed in feature branches and reviewed through pull requests. No private chats or personal knowledge files belong in this repository.

## Principles

- **Your data stays yours:** local browser storage by default; optional Google Drive backup, not public GitHub.
- **Evidence first:** memory candidates reference original messages and require human approval.
- **No invented personality:** a digital-self profile summarizes approved evidence, not an authoritative personality diagnosis.
- **Portable:** explicit exports and a documented format.
- **Transparent limits:** no claim of automatic access to every AI conversation, perfect import, or verified real-world outcomes.

See the upcoming prototype pull request for installation instructions, implementation and tests.
