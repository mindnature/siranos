# SiranOS 0.2 — Import → Ask → Cite → Review

## Quick walkthrough (all examples fictional)

1. Install as an unpacked Chrome/Edge extension from `extension/` in a **separate browser profile**. The public-alpha IndexedDB is independent from any older private prototype.
2. Open **导入与云端备份**. Start with `examples/demo-conversations.json`. The app does not automatically capture vendor websites or account histories.
3. Open **向历史提问**, enter a question such as “社区花园活动有什么目标？” when you have a matching fictional sample. The system scans only **imported user messages**, retrieves evidence by local lexical relevance and shows exact message links.
4. Click **查看完整原话** for context. Click **加入记忆审核** for a specific user statement to create a **pending** candidate. It does not automatically approve that statement.
5. Open **长期记忆审核** and approve or dismiss the candidate; visit **数字人格** to see the confirmed evidence. Revoking confirmation removes it from the current projection.

## What the question-answering mode is *not*

- This is an **offline extractive evidence brief**, **not** an LLM-generated answer, semantic embedding search, or verification of real-world events.
- The answer is limited to already-imported local data. No result does not mean the user never said it.
- Assistant-generated messages are excluded from the evidence answer, to avoid treating AI suggestions as facts about the user.
- Approval means the user approved retention of the quote, not that the quote is true. Source hash changes invalidate earlier approvals.
- The application **never** sends a question or evidence to an external model during offline Q&A.

## Streaming import limits

`chat.html` generated by a supported ChatGPT export is parsed using its embedded `var jsonData = [...]` array. Large `conversations-000.json` style **root arrays** can be streamed object by object. The reader supports progress and cancellation between chunks; each conversation has a 64 MiB safety cap. This pathway has been tested on **synthetic** records, not benchmarked on all real-world exports.

ZIP64 and multi-gigabyte ZIP decoding **remain unsupported**; first extract the vendor ZIP outside the browser and import the appropriate individual JSON files or ChatGPT `chat.html`. Images, attachments, video and other media are not indexed or backed up by this importer; always keep the original vendor export. JSON exports with a root object may use the existing smaller-file importer. Stream processing is bounded per conversation, but long-running imports may still exceed a browser's storage quota; verify successful record counts and keep backups.

## Privacy guarantees and limitations

- No real-person fixtures, custom profiles, GitHub personal data or OAuth tokens bundled.
- Source data stays in the browser unless the user explicitly enables Google Drive sync. Google backup is **not end-to-end encrypted**.
- Questions and their local matching do not leave the browser.
- Source references include original quotes. Treat the JSON exports as confidential.
- Google Drive OAuth requires **each installer's** own Chrome extension client ID. It is not preconfigured or tested end-to-end on a production account.
